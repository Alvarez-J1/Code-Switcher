# File Map

- `index.html` contains the page structure and CDN links.
- `styles/style.css` contains layout, components, responsive rules, and visual effects.
- `styles/fonts.css` contains font declarations.
- `js/script.js` contains tab switching, copy behavior, and footer animation.
- `js/stars.js` creates the falling star elements.
- `images/` contains local visual assets.
